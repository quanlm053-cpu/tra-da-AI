# Giao diện Trà đá AI

Thành phần React, TypeScript, Three.js và React Three Fiber của Trà đá AI.

Xem [README cài đặt toàn hệ thống](../README.md). Chạy từ thư mục gốc bằng `start.ps1 -Component office`, mở http://localhost:8766/lending. Backend Trà đá AI dùng cổng 8767.

Mã nền kế thừa Munizada/agent-office theo MIT, giữ nguyên LICENSE. [README upstream](docs/README-upstream.md) mô tả bản gốc, không phải hướng dẫn triển khai tích hợp Trà đá AI. Các đường dẫn demo và workflow upstream không thay cho backend của bản này.
